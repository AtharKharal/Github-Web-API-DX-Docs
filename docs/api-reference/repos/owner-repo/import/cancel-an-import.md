# Cancel an import

Stop an import for a repository.

```http
DELETE {{baseUrl}}/repos/:owner/:repo/import
```




## Parameters

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `owner` | `string` | `Path` | `Yes` | (Required)  |

| `repo` | `string` | `Path` | `Yes` | (Required)  |
