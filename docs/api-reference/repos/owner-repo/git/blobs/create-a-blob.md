# Create a blob



```http
POST {{baseUrl}}/repos/:owner/:repo/git/blobs
```




## Parameters

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `owner` | `string` | `Path` | `Yes` | (Required)  |

| `repo` | `string` | `Path` | `Yes` | (Required)  |



## Request Body

=== "JSON"

    ```json
    {
        "content": "<string>",
        "encoding": "utf-8"
    }
    ```
