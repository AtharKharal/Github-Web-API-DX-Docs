# Delete a GitHub Pages site



```http
DELETE {{baseUrl}}/repos/:owner/:repo/pages
```

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `owner` | `string` | `Path` | `Yes` | (Required)  |

| `repo` | `string` | `Path` | `Yes` | (Required)  |
