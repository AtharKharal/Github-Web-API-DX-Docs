# Update information about a GitHub Pages site



```http
PUT {{baseUrl}}/repos/:owner/:repo/pages
```




## Parameters

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `owner` | `string` | `Path` | `Yes` | (Required)  |

| `repo` | `string` | `Path` | `Yes` | (Required)  |



## Request Body

=== "JSON"

    ```json
    {
        "cname": "<string>",
        "source": "<string>"
    }
    ```
