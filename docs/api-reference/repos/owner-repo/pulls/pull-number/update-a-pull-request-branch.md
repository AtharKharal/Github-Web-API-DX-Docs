# Update a pull request branch

Updates the pull request branch with the latest upstream changes by merging HEAD from the base branch into the pull request branch.

```http
PUT {{baseUrl}}/repos/:owner/:repo/pulls/:pull_number/update-branch
```




## Parameters

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `owner` | `string` | `Path` | `Yes` | (Required)  |

| `repo` | `string` | `Path` | `Yes` | (Required)  |

| `pull_number` | `string` | `Path` | `Yes` | (Required)  |



## Request Body

=== "JSON"

    ```json
    {
        "expected_head_sha": "<string>"
    }
    ```


## Responses


=== "415 Unsupported Media Type"

    Preview Header Missing

    ```json
    {
     "message": "enim velit officia",
     "documentation_url": "et proident"
    }
    ```


=== "202 Accepted"

    response

    ```json
    {
     "message": "Updating pull request branch.",
     "url": "https://github.com/repos/octocat/Hello-World/pulls/53"
    }
    ```

    Forbidden
