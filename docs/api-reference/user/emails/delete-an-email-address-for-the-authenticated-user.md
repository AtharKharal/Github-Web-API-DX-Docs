# Delete an email address for the authenticated user

This endpoint is accessible with the `user` scope.

```http
DELETE {{baseUrl}}/user/emails
```





## Request Body

=== "JSON"

    ```json
    {
        "emails": [
            "<string>",
            "<string>"
        ]
    }
    ```
