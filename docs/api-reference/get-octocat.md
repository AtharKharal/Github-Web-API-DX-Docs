# Get Octocat

Get the octocat as ASCII art

```http
GET {{baseUrl}}/octocat?s=<string>
```




## Parameters

| Name | Type | In | Required | Description |
| :--- | :--- | :--- | :--- | :--- |

| `s` | `string` | `Query` | `No` | The words to show in Octocat's speech bubble |
