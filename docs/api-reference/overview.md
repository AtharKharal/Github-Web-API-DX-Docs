# API Reference Overview

Welcome to the complete reference for the GitHub Web API. The API is organized into several key categories of resources.

---

## Core Resources

* **Users** [users/index.md]: Manage user profiles, followers, and settings.
* **Repositories** [repos/index.md]: Interact with repository content, commits, and releases.
* **Organizations** [orgs-org/index.md]: Manage organization members, teams, and webhooks.

## Collaboration & Workflow

* **Issues** [repos/owner-repo/issues/index.md]: Track and manage repository issues and comments.
* **Pull Requests** [repos/owner-repo/pulls/index.md]: Review and merge pull requests.
* **Actions** [repos/owner-repo/actions/index.md]: Automate your workflow with GitHub Actions.

## Advanced & Utility

* **Search** [search/index.md]: Search for repositories, users, and code across GitHub.
* **Markdown** [markdown/index.md]: Render Markdown content using the GitHub renderer.
* **Gists** [gists/index.md]: Manage Gists and their comments.

---

## How to use this reference

Each endpoint page contains:

1. Method & URL: The HTTP method and path for the request.
2. Description: A detailed explanation of what the endpoint does.
3. Parameters: A table of path, query, and body parameters.
4. Examples: Real-world request and response snippets.
5. Status Codes: A list of possible HTTP status codes and their meanings.
